## What to watch for

Run the descending preset. It costs nothing to build, because a descending array is already a valid max-heap. Every parent is already bigger than its children and not a single swap is needed.

Now run ascending. It is the most expensive preset in both phases. Building it means dragging the largest values up from the tail of the array. Emptying it means the values you pull back to the root are the smallest ones left, so they sink the whole depth of the tree before settling.

The lesson is not that one arrangement is cheap and another dear. It is that a heap does not care about sorted order at all. Descending order happens to satisfy the heap rule by accident. Ascending order violates it as thoroughly as an arrangement can. Neither one is more sorted than the other.
